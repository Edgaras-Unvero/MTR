# MTR 2026 Rally Control

## GitHub Pages paleidimas

1. GitHub sukurkite naują public repository, pvz. `MTR-2026`.
2. Įkelkite `index.html` į repository šakninį katalogą.
3. Atidarykite **Settings → Pages**.
4. Prie **Build and deployment / Source** pasirinkite **Deploy from a branch**.
5. Branch: **main**, folder: **/(root)**.
6. Spauskite **Save**.
7. Po kelių minučių GitHub parodys jūsų viešą HTTPS adresą.

Telefone atidarykite tą adresą Safari arba Chrome.

## Svarbu
Duomenys saugomi naršyklės localStorage. Naudokite tą pačią naršyklę ir tą patį GitHub Pages adresą. Periodiškai eksportuokite JSON kopiją.
