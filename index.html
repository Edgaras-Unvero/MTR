Authorization: Bearer {token} Accept: application/json 1. TRANSACTIONS =============== GET /transactions Get transactions ---------------- This endpoint allows you to retrieve a paginated list of transactions for a specified date range. Transactions can optionally be filtered by transaction provider. Query parameters ---------------- date_from Type: date Required: Yes Description: Start date of the transaction period. Format: YYYY-MM-DD Example: 2026-07-15 date_to Type: date Required: Yes Description: End date of the transaction period. Format: YYYY-MM-DD Example: 2026-08-10 provider Type: string Required: No Description: Filters transactions by transaction provider. Only supported transaction providers can be used. Example: as24 per_page Type: integer Required: No Description: Number of transactions returned per page. Default: 100 Minimum: 1 Maximum: 1000 page Type: integer Required: No Description: Page number to retrieve. INVOICE VALIDATION ===================== POST /invoice-validate Validate invoice prices ----------------------- This endpoint allows you to submit invoice transaction records and retrieve the corresponding Unvero price for each transaction. The response provides the Unvero price with VAT and without VAT. The endpoint also returns additional custom attributes included in the request. This makes it possible to include your own invoice values, transaction identifiers, or other reference data and receive them back together with the Unvero validation result. Request body ------------ The request body must contain an array of transactions. Required transaction attributes -------------------------------- station_id Type: string Required: Yes Description: Gas station terminal ID. The value should correspond to the terminal ID used by Unvero. Example: 7975AS24 date_and_time Type: datetime Required: Yes Description: Date and time of the transaction. Format: YYYY-MM-DD HH:mm:ss Example: 2026-07-09 10:57:27 currency Type: string Required: Yes Description: Currency of the transaction. Example: EUR product Type: string Required: Yes Description: Unvero product type. Examples: diesel, ad_blue, sp_95 Additional attributes --------------------- Additional attributes can be included in each transaction object. They are returned unchanged in the response and can therefore be used to match the Unvero result with data from your invoice, ERP, TMS, or accounting system. Example custom attribute: { "INVOICE_NET_PRICE": 1.6183 } INVOICE_NET_PRICE is only an example. Custom attributes can be used for reference purposes. Request example --------------- curl --location 'https://v2.unvero.lt/api/invoice-validate' \ --header 'Authorization: Bearer {token}' \ --header 'Accept: application/json' \ --header 'Content-Type: application/json' \ --data '[ { "station_id": "7975AS24", "date_and_time": "2026-07-09 10:57:27", "currency": "EUR", "product": "diesel", "INVOICE_NET_PRICE": 1.6183 }, { "station_id": "5217AS24", "date_and_time": "2026-07-08 19:56:34", "currency": "EUR", "product": "diesel" } ]' Response example ---------------- [ { "station_id": "7975AS24", "date_and_time": "2026-07-09 10:57:27", "currency": "EUR", "product": "diesel", "INVOICE_NET_PRICE": 1.6183, "unvero_status": null, "unvero_net_price_with_vat": 1.942, "unvero_net_price_without_vat": 1.61833, "unvero_currency": "EUR", "unvero_exchange_rate": null } ] Response fields --------------- unvero_status Type: string|null Description: Contains a validation status or error message when Unvero cannot determine a price. When validation succeeds, the value is null. unvero_net_price_with_vat Type: number|null Description: Unvero net price including VAT applicable to the transaction. Returns null when a matching price cannot be determined. unvero_currency Type: string|null Description: Currency of the returned Unvero price. This may differ from the currency supplied in the request depending on the underlying price data. unvero_exchange_rate Type: number|null Description: Exchange rate associated with the returned Unvero price, when applicable.
